# TruthLens — AI Deepfake & Misinformation Awareness

A responsive, beginner-friendly awareness website about AI-generated deepfakes, misinformation and disinformation. Built using HTML, CSS and vanilla JavaScript.

## Features
- Responsive landing page and mobile navigation
- Simple explanations of deepfakes, misinformation and disinformation
- Common warning signs and limitations of AI detection tools
- Five-step media verification guide
- Interactive verification checklist
- Myth vs. fact section
- Five-question quiz with instant feedback and score
- Links to useful verification and cybercrime-reporting resources

## Run locally
1. Download and extract the ZIP file.
2. Open the extracted `ai_deepfake_misinformation_awareness` folder.
3. Double-click `index.html` to open it in your browser.

No installation, backend, database or API key is required.

## Upload to GitHub
1. Sign in to GitHub and create a **New repository**.
2. Give it a name such as `ai-deepfake-awareness`.
3. Choose Public or Private, then create the repository.
4. Select **Add file → Upload files**.
5. Upload `index.html`, `style.css`, `script.js` and `README.md` (or drag the extracted folder's contents into the upload area).
6. Commit the changes.

### Optional: publish with GitHub Pages
1. Open the repository's **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Select the `main` branch and `/ (root)` folder, then save.
4. Wait for GitHub Pages to publish the site. The URL will appear in the Pages settings.

## Important note
This is an educational awareness project, not a deepfake-detection system. It does not upload, analyse or classify user media. Visual clues and automated detector results are not conclusive proof; verify sources and context.

## Suggested project description
An interactive digital-literacy website that educates users about AI deepfakes, misinformation and disinformation through awareness content, practical verification steps, a checklist and a knowledge quiz.
